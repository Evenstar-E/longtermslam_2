## 比较内容

1. MAP：选概率最大的解释并提交拍摄返航。
2. Ask first：先问再执行；若所有解释允许同一个拍摄动作，则跳过问题。
3. One-step task VOI：比较一个合法动作后接 MAP 的任务代价；实际执行时滚动重算。
4. Two-step lookahead：通用两层动作/观测树，末端接 MAP，每次实际决策重新前瞻。
5. Three-step lookahead：同上，深度为三层。报告完整执行期望，而非截断预测值。
6. Exact belief DP：对全部合法动作和观测分支做有限时域动态规划；没有预知真值。

目标函数为 `250 × 失败概率 + 期望资源成本 + λq × 期望询问数`，`λq ∈ {0,5,20,60,120}`。询问的物理成本另外从资源预算扣除。不能把某一权重下的最优目标值直接等同于最高成功率。

第一轮为 20 个布局 × 6 类任务 × 5 个成本权重 × 4 个方法 = 2,400 次策略评估、24,000 条配对采样轨迹。第二轮每组 6 个方法，共 3,600 次策略评估、36,000 条轨迹。布局是独立重复单位；随机轨迹不是新场景。初始不可能任务保留并单独报告。

`expected.csv` 使用全部有限观测分支的期望值，不是十次采样的均值。`episodes.csv` 和 `traces.jsonl` 是真实执行本离散模拟器得到的采样记录。配对差异区间以布局为单位，只描述当前合成生成器的变异。

## 早期有限图预实验的建模边界

- 仅两个符号任务解释；没有实现参考系/历史时间的语言解析。
- 已知静态安全路径图，真实位姿，准确先验和观测似然。
- 可靠二元询问；每观察点最多观察一次；纯意图歧义的观察似然相同。
- `finish` 是到指定拍摄视点、拍一次照片并返航的宏动作。实际运动路径完整记录，提交后不再获取信息。
- 决策时域按宏动作计数。精确性仅针对这一有限模型，不是连续无人机控制最优性。
- 所有移动/观察/询问保留返航资源。这里没有真实碰撞模型，不能以零模拟碰撞宣称安全性。
- “拍摄前失去可恢复性”是离线诊断；真值只在模拟环境与评价器中出现。
- 精确动态规划和通用多步前瞻均为参照算法，不是本项目的新方法。三步在图模型测试中达到精确指标，不是任意模型的最优性证明。后续任务审查和方向复核已完成，当前视觉阶段见本文开头。
