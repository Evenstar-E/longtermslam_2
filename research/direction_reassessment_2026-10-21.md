# 方向级复核：跨次无人机巡检的任务价值、算法边界与去留判断

日期：2026-10-21。性质：基于现有实验与本轮有界查新的研究判断，不是新算法实验报告。条件：仿真为主，无无人机，GPU配置未确认。本文更新旧提案的优先级，保留原文件与全部实验作为历史证据。

## 1. 决定

**保留有实际后果的巡检任务，调整主问题和算法模块；停止把“何时询问／两目标分支选择／普通跨次坐标配准”作为当前主贡献。**

建议工作方向：**面向跨次无人机巡检的变化感知视觉状态估计与主动复检。**

研究问题：

> 给定上次巡检的构件、表面和图像记录，当历史记录与当前图像不一致时，能否联合估计对应关系、位姿误差和局部状态变化，避免将定位、关联或成像误差误报为变化，并用有限的新观察取得正确位置上的可比较复检证据？

任务产物是“正确资产／表面对应的图像、限定状态结论和证据充分程度”，不是到达附近或拍一张照片。原提案的主模块为信念空间规划；本次建议主模块改为**变化感知的视觉关联与状态估计**，主动视角规划用于检验任务价值，现成控制器执行。

**任务值得保留，但新的算法贡献尚未成立。** Khronos、POV-SLAM、OASIS-Map、FOCUS与主动损伤巡检覆盖了重要组成部分。建议进入一次有停止条件的视觉验证，不建议现在以“高创新专用规划算法”立项。

这是一项实质方向调整。自然语言可以作为任务入口，但去掉语言、改用结构化任务单后，核心问题仍应存在。若必须以VLN为论文中心，应另选方向，不能把此方案称为原VLN规划课题已经验证成功。

## 2. 重要任务：交付什么，失败影响什么

FHWA报告讨论巡检图像归档、跨年比较和缺陷趋势分析，也记录了调整曝光并检查图像细节的现场过程。这支持“可追溯复检资料”的需求，不支持我们尚未测量的错误频率或节约比例。[FHWA，2021，印刷页55、58、71](https://highways.dot.gov/sites/fhwa.dot.gov/files/FHWA-HRT-21-086.pdf)

现成产品已支持重复轨迹及POI快照。Flyability官方文档要求有效重定位参考，并提示选择独特、永久特征、避免高对称区域。“按历史记录飞回去”已有工程方案，应作为强对照；产品文档不是独立可靠性实验。[Elios 3官方文档](https://knowledge.flyability.com/aircraft/elios-3/elios-3-feature-details/elios-3-autonomous-repeat-flight-and-comparison-over-time)

| 工作环节 | 应交付结果 | 错误的实际后果 | 可测指标 |
|---|---|---|---|
| 桥梁连接板、支座表面定期复检 | 同一构件同一表面的历史／当前图像及可比较区域 | 记录错挂；差视角造成假变化或无法比较 | 错挂率、可比较复拍率、误报／漏报、补采代价 |
| 修补、换件后复核 | 指定资产位置的状态记录与证据 | 将相邻未维修构件当作已维修目标；把阴影误作变化 | 位置关联、可见状态判定、拒判与覆盖率 |
| 工业管廊、钢结构周期巡检 | 带位置及历史来源的异常候选资料 | 重复结构错配造成漏查或无效复核 | 跨结构泛化、单位资源内有效复检数 |

上述具体流程是研究设计；没有完整工业操作日志证明其频率。输出辅助检查资料，不等同于承载力评估或全部人工检查的替代。重要性来自“报告是否挂在正确位置、证据是否足够”，不来自指令能否写得很含糊。

### 贯穿任务、模型和实验的例子

以下尺寸和动作是仿真设计示例，不是现场测量或已运行结果。

任务单明确指定P3连接板上游侧，附上次图像与表面ROI，要求复拍紧固件区域。本次进入桥下：

1. P3、P4局部相似，跨次定位可能错开一个构件间隔。
2. 梁体遮挡部分目标，光照不同。
3. 当前暗斑可能是阴影，也可能是一个可见紧固件缺失。

用户已经明确P3，不必再制造意图歧义。系统仍须判断当前看到的是谁、是否同一表面、是否看得清。

焦距1000像素、正视距离2米时，20毫米目标的理想投影约10像素；横向定位偏差0.10米可造成约50像素偏移。这个算术说明错误投影上的图像差分可能完全错位，不保证10像素就能可靠辨识，也不代表真实误差分布。0.1毫米细裂纹在同条件下约0.05像素，不能列为该设置的有效检测目标。

合理观察可能是先看编号或稳定构造确认位置，再侧移露出连接板，最后采集合格图像。若编号已清楚可见且配准可靠，第一步应省掉；若所有可达视角均看不清，应输出证据不足，不能输出“没有变化”。

成功产物是P3指定表面的历史／当前证据和限定结论，并记录资源、质量和时间。明确ID、普通复飞加质检如果已经能可靠完成，就接受工程方案足够。

## 3. 方向比较

| 路线 | 证据与主要问题 | 决定 |
|---|---|---|
| 原参考歧义下专用规划 | 有限模型中普通depth3已足够；真实语言必要性未建立；实验没有历史视觉机制 | 停止当前专用规划主张；不能外推否定全部历史语义问题 |
| 跨次不确定配准 | 有工程价值，但普通变换、VT&R、多次SLAM已有大量工作；有限变换候选仍脱离视觉 | 不单独作为新主线；旧v3仅保留作诊断候选 |
| 跨次复检中的变化感知状态估计 | 对应错挂、假变化、漏查和无效复拍；近邻很强，算法增益待证明 | 推荐有条件探索；先验证真实机制，不宣布高创新 |

增加目标数、图规模、语言长度或网络规模，都不能自动提高研究意义。推荐路线必须在明确目标、允许普通工程工具的条件下仍然有价值。

## 4. 本轮近邻核验与创新边界

这是针对立项的有界检索，不是系统综述。实际读取范围和检索记录见[证据登记](../data/direction_review_v1/evidence.json)。只使用原始论文、作者项目／仓库及政府／产品文档支撑技术判断。

| 工作 | 已覆盖的内容 | 对本方向的约束 |
|---|---|---|
| [Urbex，2026预印本](https://arxiv.org/html/2610.18356) | 地标查询、缩放、斜视渲染驱动主动空间搜索；附录E讨论校准／渲染依赖 | 多视图主动落地不是新点；工具视图与物理飞行输入、代价不同，原成绩不能直接作为UAV巡检对照 |
| [POV-SLAM，RSS 2023](https://arxiv.org/html/2307.00488) | 对可能变化的对象建模可靠性，利用变分估计联合优化位姿与对象一致性 | 变化与位姿联合推断已有；加一个变化开关或鲁棒核不足 |
| [Khronos，RSS 2024](https://arxiv.org/html/2402.13817) | 时空度量语义地图、局部片段与全局优化、几何证据区分未看到与不存在 | 历史地图、遮挡判断和变化推断本身均非新贡献 |
| [Living Scenes，CVPR 2024](https://arxiv.org/html/2312.09138) | 实例化点云的跨时匹配、配准和累积重建 | SE(3)表示加跨时对象关联也已有；不能只以六自由度区分 |
| [OASIS-Map，2026预印本](https://arxiv.org/html/2607.14899) | 跨次稠密语义对应、对象关联与变化标签；III-A由外部SLAM提供统一世界系位姿 | 直接视觉关联对照；前端依赖不等于不能容忍任何位姿误差 |
| [FOCUS，2026-10预印本](https://arxiv.org/html/2610.05639) | 概率融合几何与3DGS外观，区分保持、替换、移除，并处理渲染及相关观测不确定性 | 很接近拟议证据模型；外观、几何、历史、贝叶斯的组合不能作为创新 |
| [UADS-DRL，2025](https://www.dpi-proceedings.com/index.php/shm2025/article/viewFile/37531/36104) | 分割不确定性引导主动损伤观察与多时刻融合 | “不确定就换视角，拍清损伤”不是新任务思想 |
| [Sight Over Site，官方项目](https://sight-over-site.github.io/) | 将目标可见性纳入巡检目标，学习有效到视点路径 | “到达不等于完成巡检”已有方法化工作 |
| [Bucci与Ridolfi，2026](https://doi.org/10.1016/j.oceaneng.2026.125170) | 多次任务、主动语义SLAM、覆盖规划和变化检测集成 | 多次地图加主动规划加变化检测作为系统组合也已有，换载体不自动创新 |

**对照后不能声称：只要把位姿误差与真实变化分开，就是新理论。** Khronos和POV-SLAM已涉及这一类问题；FOCUS进一步覆盖外观不确定性。论文各自的边界不能拼接成一个未经验证的“空白”。

## 5. 算法贡献应落在哪个模块

| 模块 | 定位 | 必须成立的证据 |
|---|---|---|
| 任务输入／语言 | 历史记录、明确资产ID、目标表面；VLM可辅助解析 | 用结构化任务单替代语言后，核心困难仍存在 |
| 视觉表示与状态估计 | **拟议主贡献**：保留对应／位姿多解，估计局部变化证据，避免过早错误融合 | 相同帧、前端、轨迹和算力下，状态／证据判断优于强对照 |
| 主动观察规划 | 次级任务验证，先采用通用VOI／短时域信念规划 | 若现成规划足够就使用；独立证明求解瓶颈后才研究新规划器 |
| 控制 | 现成轨迹跟踪和仿真控制 | 不声称新飞控 |
| 系统集成 | 必要工程交付 | 与算法新颖性分开评价 |

### 拟验证的算法假说

**在局部变化和跨时对应互相干扰时，保留对应多解、对位姿及成像干扰边缘化的局部证据模型，比“先锁定一个配准／对应，再判断变化”的串行方案，更能支持可靠复检。**

具体拟改的是“历史表面—当前观察”的证据因子：

- 几何和稳定上下文约束位置、身份；局部ROI评价所关心的状态变化。
- 位姿误差应在多个背景区域产生可由同一变换解释的残差；真实局部变化需解释目标区域，并与合理视角下的新观察一致。
- 稳定上下文不能由仿真真值指定，需估计其可靠性，允许背景变化。
- 重复结构下保留多个关联／位姿模式，不把多峰坐标平均成一个不存在的表面。
- 输出可校准的后验和证据充分程度，而不只输出相似度分数。

初版可用冻结视觉特征、显式几何与通用多假设估计构建对照。进一步的方法研究必须明确新的条件似然、特征分解或计算近似改善了什么。**多假设、边缘化、因子图、贝叶斯更新和信息增益本身都是已有工具。** 如果通用多假设方法或直接近邻已经解决问题，只能得到“采用现成方法”的结论。

### 初步数学模型

历史记录为

\[
r_i=(\mathrm{asset}_i,\Omega_i^0,I_i^0,K_i^0,\mathcal M^0),
\]

包括明确资产位置、目标表面、图像、内参和历史地图。资产位置和物理零件身份分开：同一安装位置换件，应记录状态变化，不能仅因位置不变就认定为同一实例。

以历史地图坐标系固定规范自由度。隐状态为

\[
s_t=(X^{0:1},A_t,\Delta,\nu_t),\qquad
b_t(s)=p(s\mid r_i,o_{1:t},u_{1:t-1}).
\]

X包含历史／当前位姿及跨次关系；A为当前观测与历史表面的对应，含未匹配；Δ为真实局部状态变化；ν为可见性、光照等干扰。资源B单独记录。“证据不足”是判断状态，不与真实的保持／变化／移除混为一谈。

一个待实现的因子化模型是

\[
b_t\propto p(X^{0:1},A,\Delta,\nu)
\prod_\ell\psi_{\rm odo}^\ell(X)
\prod_g\psi_{\rm ctx}^g(o_g\mid X,A,\Delta,\nu)
\prod_j\psi_{\rm roi,\theta}^j(o_j\mid X,A,\Delta,\nu).
\]

这是建模模板，不是已经成立的新算法。相邻帧、共享特征和同一表面上的重复观察不能无限作为独立证据相乘；初版可按时间／视角块更新，再检验校准。

关键变化证据对位姿和对应关系积分，而不只代入一个最优配准：

\[
p(o_{\rm new}\mid \Delta=d,h_t)
=\sum_A\int p(o_{\rm new}\mid X,A,d,\nu,h_t)
p(X,A,\nu\mid \Delta=d,h_t)\,dX\,d\nu .
\]

对数似然比

\[
\Lambda=\log
\frac{p(o_{\rm new}\mid\Delta=\mathrm{changed},h_t)}
{p(o_{\rm new}\mid\Delta=\mathrm{unchanged},h_t)}
\]

表达新证据支持真实变化的程度。实际实现还需变化类先验、候选外模型、近似求解和校准数据；这些均未实现。模型形式不等于对先验或正确关联拥有真值。

合格复拍条件为

\[
G_i(c)=G_{\rm identity}\land G_{\rm surface}
\land G_{\rm visibility}\land G_{\rm resolution}
\land G_{\rm quality}\land G_{\rm return}.
\]

策略用估计，评价器用隔离真值及可测图像质量。不能让策略读取真值G，也不能把拍摄宏动作直接设为成功。

用L表达错挂、误报、漏报和证据不足代价，普通贝叶斯决策风险为

\[
\mathcal R(b)=\min_{d\in\mathcal D}\mathbb E_{s\sim b}L(d,s).
\]

通用一步观察价值为

\[
a^*=\arg\max_{a\in\mathcal A_{\rm feasible}}
\{\mathcal R(b_t)-\mathbb E_{o\mid a,b_t}\mathcal R(b_{t+1})
-\lambda c(a)\}.
\]

该式是已有决策理论的应用，作为规划基线，**不是新理论**。它可选择先看位置锚点还是拍目标表面；普通多步规划处理先移动才能观察的情况。耗时、成像条件、返航资源均须由实际场景及轨迹计算。

### 普通工具为什么有时足够，有时仍需实验

| 条件 | 应接受的解释 |
|---|---|
| 准确世界坐标、可靠ID、清晰视角 | 普通变换与点选通常足够指定位置，不应人为破坏它们 |
| 只点选历史图像 | 明确历史ROI和意图，但未自动测出本次对应和可见性 |
| 人能在当前画面准确点出目标 | 可直接消除大部分关联问题，应保留为强辅助条件；不能故意抬高其成本 |
| 使用成熟SLAM和变化检测 | 可能已足够，必须实测；不能凭论文未写UAV就判定不足 |
| 配准／关联多解且观察条件变化 | 串行单解可能误解差异，这是待验证假说，不是本地实验事实 |

## 6. 验证不能继续删掉核心困难

详细设计见[视觉复检验证规格](visual_reinspection_validation_spec_2026-10-21.md)。

必须具备：

1. 至少两次采集，历史图像、位姿估计和表面记录来自第一次。
2. 当前RGB-D或可审计渲染经过视觉前端生成对应／残差，不用手设0.8识别概率代替。
3. 三维遮挡、朝向、距离、相机独立姿态和分辨率共同决定证据。
4. 无真实变化但光照不同、有真实变化但位姿相同、错配但不变、变化与错配共存等配对条件。
5. 主动动作实际改变图像，移动耗时，拍摄后继续推断；不能免费预览全局。
6. 准确配准＋清楚ID、不可观测、细节小于可辨尺度等负对照。

先固定轨迹比较估计器，再固定估计器比较观察策略，最后交叉替换并闭环执行。分层用于归因，不能再删掉要主张的历史、视觉和几何。飞行动力学可后置，但第一轮不能声称真实飞行能力。

3RScan适合真实跨次关联验证，但不是桥梁数据。ChangeSim适合工业场景变化及非目标扰动，发布的固定序列并不等于任意飞行的交互环境。它们不能单独证明完整UAV闭环性能。[3RScan官方仓库](https://github.com/WaldJohannaU/3RScan)、[ChangeSim论文](https://arxiv.org/abs/2103.05368)

## 7. 去留条件与可行性

| 观察结果 | 方向决定 |
|---|---|
| 显式ID＋普通配准／复飞＋质检已达到任务要求 | 停止新算法方向；按工程方案交付 |
| 同样图像下现成方法失败，真值对应／位姿上界成功 | 存在估计瓶颈；再检验拟议因子，不自动认定它可解 |
| 新估计器在固定轨迹有效，通用规划已足够 | 主贡献写在表示／感知，不强加新规划算法 |
| 只因多观察而有效，固定帧下无增益 | 收益属于采集策略／预算，不能声称新表示成立 |
| 现有主动方法也足够 | 采用已有方法，系统价值与新颖性分开 |
| 完美对应和位姿下仍看不清 | 调整传感器／任务边界，不能靠推理补出不存在的证据 |
| 只在自造极端重复场景有效 | 限定为机制结果，不证明工业价值 |

仿真足以开展上述视觉机制研究，不必先训练大VLM或复现Urbex默认多GPU训练。现有有限图代码主要能复用日志和评估，无法通过加参数变成视觉验证环境。最主要风险是已有方法已足够、图像能力才是瓶颈、公开素材不匹配，以及方法只对自建场景有效。

若素材不包含目标机制，应报告验证条件不足，不能又换成一个符号小图。样本、成本和效果门槛须在运行前明确；没有业务数据时，不把研究者设定的门槛称为行业标准。

**下一项工作：交付一个两次采集的可视复检样例包，运行普通配准／变化检测与真值诊断，指出具体哪张图、哪个关联、哪个视角造成正确或错误结论。** 样例机制验收后才冻结多场景实验，依据强基线结果决定是否开发新估计器。
