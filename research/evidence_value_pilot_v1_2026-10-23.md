## 结论与主线判断

这次完成了新算法训练和决策比较，推进的是主动证据选择/规划中的价值估计模块。交互模型比平坦RBF的总报告损失8.50降至4.25，但普通覆盖率组合损失为0，去掉跨片段协方差的模型损失为1.05。当前“共享误差关系＋学习交互”的核心创新收益没有成立，不应因局部优于平坦模型就继续扩样确认。

模型部署与输入隔离是工程工作；“实际估计器报告收益能否由关系和交互泛化预测”是研究问题，本轮已经得到直接负面/混合证据。覆盖率组合在本菜单中达到24/24正确量化，学习模型尚未超越。这个结论只限当前简化场景和两次采集菜单，不证明所有真实复检问题都不需要主动取证。

## 实际做了什么

- 使用48个初始H0/C0图，每个图编码成31个选项、每选项427维：STOP、22单动作、8预定组合。仅这些初始图进入模型，未把未来状态图当预测输入。
- 16训练家族480非STOP分支标签，16校准家族选择超参数，16开发家族评价；同一家族所有分支在同侧。不是480个独立样本。
- 平坦线性3组超参数；其余5种核模型各9组，共48候选拟合配置、66次核线性系统求解。结构模型每配置拟合单动作及交互两个回归器；不宣称相同计算开销。
- 保存6个最终模型、校准搜索记录、全侧冻结预测，然后才由评价阶段加载开发标签。准备阶段只将既有标签按家族分文件，已知标签审计史如实保留。
- 复用先前实际求解的终点，本轮新增共同几何估计器调用为0。全部3种价格的480条“方法×开发家族×价格”记录保存在decisions.json。没有GPU/GNN训练，没有完整自适应闭环。

## 模型与公平性

真实训练目标 g(o)=L(initial)-L(after o)。结构模型：

    g_hat(a,b) = f(x_a) + f(x_b) + h(x_ab)
    h_target(a,b) = L(a) + L(b) - L(a,b) - L(initial)
    option = argmax_o [ g_hat(o) - lambda * number_of_acquisitions(o) ]
    g_hat(STOP) = 0

这是条件均值的核回归近似；每个分支只有一个观测实现，不是精确期望或最优Q。f/h共用一组校准超参数，避免两重独立搜索；模型不基于真实终点最小值决定动作。

平坦线性与通用RBF也得到相同的全局类型矩、动作属性、已见面/构件关系、共享及完整联合协方差汇总和动作对特征。没有通过信息权限差异制造结构优势。但427维是有损汇总，尚非可学习图消息传递；当前比较检验显式价值分解，不是完整GNN。去协方差对照仅把跨片段共享/联合协方差通道置零，保留节点边际方差、源结构计数和其他关系，不能写成“所有不确定性被去除”。

主价格lambda=.05/次采集在运行前固定；0和.2也全部报告，无开发调价。该量纲是人为设定的任务损失偏好，不是工程经济成本。真实返航路程、字节和报告质量分别保留；决策目标并未直接优化路程或CPU。

风险阈值由校准选为0，开发场景均未触发停止，因此coverage_risk_stop与coverage_bundle相同。这是普通参照的结果，不是本轮学出了停止优势。

候选交互MSE0.8687反而高于加和模型的零交互对照0.8191。候选某些动作选择改善，不能据此宣称整体交互预测可靠；全局MSE与任务最优选项也不是同一目标。

主对照各自经校准选参数，所以加和与候选的单动作回归器正则化不同。为检查归因，完成后追加一次明确标为POST_HOC的诊断：固定候选单动作回归器，不训练、不调参数，只移除h或改用训练集交互均值。三者总损失分别为4.25、5.50、5.50。因此同一f下h有1.25的局部选择收益，但仍不胜覆盖率、不能解释共享协方差价值，也不替换原定对照。

## 问题分类与停止边界

1. 工程：编码单测在冻结前发现片段特征宽度9被写成10，已改为从schema取宽度；该修复不算创新。序列化、哈希和文件隔离同属工程。
2. 算法：交互回归的开发误差未胜零交互；固定f的局部收益存在但有限。训练家族只有16、427维有损特征、近似协方差等都是可能限制，尚无因果证据说明哪一个导致失败。
3. 核心主张：去掉跨片段协方差后决策反而更好，当前结果不支持“共享误差关系是收益来源”。不能把表现更好的消融临时改名为新创新。
4. 评估边界：普通覆盖率组合已在当前开发菜单零损失，继续扩同类seed、调当前核参数或提高候选数量不是有依据的下一步。没有执行旧256确认，没有调整v8或旧门槛。

下一项应固定当前候选和结果，沿完整任务做一次可兑现的边界检验：把冻结覆盖率组合与冻结候选接到相同完整获取/返航接口，用前瞻定义的外部几何/可见性变化分布评价迁移及选择错误；先限定工程上确实发生的变化来源，所有强参照保留，不按候选输赢筛场景。若没有独立可检验的现实机制，应停止该候选核心贡献，重新选择算法机制，不能自动启动另一轮调参。普通图Q与匹配两步自适应规划目前仍未实现，本轮也不冒充完成论文全套强对照。
