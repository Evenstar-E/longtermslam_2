# 可撤销表面增量：已实现模型与预先固定的比较协议

日期：2026-10-24。类型：真实数据开发实验，不是新理论、论文创新性确认或独立测试集结果。本文在本轮身份评分前写入，数值结果另存结果报告。

## 本轮要解决的具体问题

第二期观测可能既包含真正新露出的表面，也包含被错误归入某一历史资产的表面。冻结档案丢掉前者；永久硬融合保留后者。需要让第三期的观测能够改变第二期表面的归属，同时保留每个增量的来源，不能把自己的补全当成新的传感器。

初始历史档案仍采用数据集给定身份。当前身份不是已知真值：第二、三期用已封存 Rescan 原生预测初始化归属和位姿。五种方法共享初始化。当前所有原始点（包括背景、漏检残余、小片段）进入输入，没有按真实身份或预测类别裁剪候选；当前预测语义仅作软代价。当前新生/未知统一用空标签处理，尚未实现可靠的新生资产建模。

第一次工程试运行 v1 以最近历史表面初始化全部标签。这会先排除真正的新可见面，不能公平检验保留补全的能力，因此在评分前停止；保留原代码和中间结果。v2 使用原生预测归属初始化，不修改任何已有封存实验。不是看到评分后选择有利初始化。

## 变量与实际计算公式

历史资产 i 的不可变观测点集为 H_i；历史材料锚点 a_i 是 H_i 中离其均值最近的实际观测点，后续不随可见面改变。当前期 t∈{1,2} 的点为 x_tn，颜色 c_tn，预测语义 s_tn。求解变量是点级身份 z_tn∈{unknown,1,…,M} 和每资产每期唯一刚体 T_ti；同一个原生片段可以被拆成多个身份，所有同身份点共享 T_ti。

当前点映回资产坐标：q_tni=T_ti^{-1}x_tn。保留来源的增量为

\[
U_{ti}(z,T)=\{(q_{tni},c_{tn},t,n):z_{tn}=i\}.
\]

因此修改 z 或 T 会重新生成增量；并非在融合点云上再乘一个权重。每个观测增量最多有一个当前身份，原始输入不被覆写。

对任一参考表面 S，先取几何最近邻 k*=argmin_k ||q-S_k||，再计算

\[
d(q,c;S)=\min(\|q-S_{k^*}\|/0.075,1)^2
 +0.2\operatorname{mean}[(c-C_{k^*})^2].
\]

颜色归一化到 [0,1]。这是几何最近邻加颜色代价，不是联合颜色距离下的精确最近邻。当前点的条件评分为

\[
e_{tni}=\min\{d(q_{tni},c_{tn};H_i),\;0.1+d(q_{tni},c_{tn};\widetilde U_{si})\}
 +0.1\mathbf1[s_{tn}\ne s_i],\qquad s=3-t.
\]

空增量的第二项视为无穷；空标签代价为 0.75。冻结对照只用第一项。每个点最终比较**全部初始资产**和空标签，没有 top-k 身份门槛。每次查询只使用历史或**另一当前期**，本期表面不能解释自己的观测。

此评分是确定性的交替估计代理，**没有宣称为归一化似然、真正的联合后验或收敛 EM**。双向使用观测的条件代价存在相关性；不能以“每期各算一次”宣称统计独立证据增加。共享表面更新会改变下一轮代价，当前没有全局目标单调下降保证。

## 本轮新增的可检验约束：初始档案支持的来源连通性

普通联合对照令 \(\widetilde U_{si}=U_{si}\)。候选方法在每个来源期、每个资产的已归属观测点上建图：两点距离≤7.5 cm 且颜色三维欧氏距离≤0.35 时连接。若某观测点距 H_i ≤7.5 cm，且对应历史点颜色距离≤0.35，则是历史支持点。

仅保留至少包含三个历史支持体素的连通分量：

\[
\widetilde U_{si}=\{u\in U_{si}:\sum_{v\in\operatorname{CC}_{si}(u)}\mathbf1[v\text{ 有历史支持}]\ge3\}.
\]

这阻止“两个都不接触初始档案的孤立观测分量互相证明身份”。它允许沿着实际观测到的连续表面扩展，而不是要求每个新点都贴近历史表面。

**这个约束可能错：**真实新视角与历史可见面之间可能没有任何连续观测路径；遮挡、细杆、稀疏采样、颜色变化会断图。另一方面，相似资产的错误对应也可能有足够历史支持点，连通并不证明物理身份。实验必须同时计算有益表面被拒绝、错误表面仍被接纳的情况。

## 共同求解与对照

| 方法 | 第二期归属/位姿可被第三期修正 | 第三期使用增量 | 增量需历史支持连通性 |
|---|---|---|---|
| frozen | 否 | 否 | 不适用 |
| hard_forward | 否 | 是 | 否 |
| joint_unrooted | 是 | 是，双向 | 否 |
| rooted_forward | 否 | 是 | 是 |
| rooted_joint | 是 | 是，双向 | 是 |

hard_forward 与 rooted_forward 的差别仅是同一已初始化第二期增量的准入约束。joint_unrooted 与 rooted_joint 共享双向循环次数。双向方法每轮更新两期，单向只更新第三期，因此整体五组不是同计算预算；主结论看成对消融，运行时间单列。

采用 4 cm 体素的实际原始点作为代表，保存原始索引、每体素原点数、完整逆映射；优化不是全分辨率连续最优解。每轮先按全部身份评分更新归属，再以加权 SVD 提议每资产的共同刚体，固定对方表面时降低所选标签代价才接纳。共六轮，参数在评分前固定。最终在每个原始点上重新评分，输出点数与原始输入严格一致。最终全点读出不会再回灌体素优化状态。

初始位姿来自共同原生布局，每身份仅一个初始化，缺失时回退历史位姿。**身份未裁剪，不等于位姿搜索完备。** 没有执行所有原生位姿候选的联合离散搜索；局部优化可能无法跳出错配位姿。没有独立的物体位移真值，材料锚点输出只是实现接口，不能报厘米精度收益。

## 评价与验收

两个已知空间的两个当前期全部预测封存后才读取逐点真值。capture2 已经在上一轮分析过，属于开发数据；同空间对象相关，不能按 37 个独立实验做显著性结论。

主指标沿用每个原始对象≥80%点被正确初始身份覆盖，严格身份与数据集允许等价身份分开；不是原论文 mIoU。等价允许集合与初始有效档案 ID 取交集，防止新生数字 ID 偶合冒充正确。第三期有 37 个初始持久资产；另报第二期结果以及来源改写的修正/损伤数量。

预先关注 a9 的正确补全与 a24 的错误竞争，但必须给全资产结果。来源污染诊断以体素代表的真值及其原点质量计算，明确不是精确全点污染比例。所有标签评价均为事后诊断，不进入推理。

需检查：增量来源可追溯、撤销后不残留、来源与目标期不同、同来源点不会被两个身份同时写入、所有原点保留、全部身份被评价、锚点不随表面更新漂移、源文件与封存结果哈希一致。

## 已有研究与创新性边界

连通性不是新工具。[Vicente、Kolmogorov、Rother，CVPR 2008](https://www.microsoft.com/en-us/research/publication/graph-cut-based-image-segmentation-with-connectivity-priors/) 已研究分割中的连通先验及求解困难；[Nowozin 与 Lampert 的连通性模型](https://www.nowozin.net/sebastian/papers/nowozin2010connectivity.pdf) 也讨论图标签的连通结构。这里没有复现它们的全局优化算法，只采用可计算的连通分量准入。

多假设、共同刚体、联合关联、表面在线更新也已有先例，见上一轮模型合同。本轮贡献候选只是“来源可撤销＋点内归属＋历史支持约束”在真实跨期档案中的具体机制。若相对普通联合对照无净收益，或不能同时保住正确新增面与避免错误写入，就不能确认为论文创新点；不靠更换术语包装结果。
