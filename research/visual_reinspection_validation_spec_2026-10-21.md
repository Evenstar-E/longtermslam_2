# 视觉复检验证规格：历史、视觉、几何必须进入实验

日期：2026-10-21。状态：待实施规格，未运行，不是实验结果或正式预注册。主判断见[方向复核](direction_reassessment_2026-10-21.md)。

## 1. 交付任务

任务输入为明确资产位置ID、指定表面ROI、历史图像及位姿记录。本次采集须找到对应表面，取得可比较图像，并输出：检测到指定可见变化／未检测到指定变化／证据不足。位置、图像质量、结论和代价共同评价。

第一阶段只研究所设相机可辨的表面状态、紧固件存在性或局部外观变化。不用家具移动证明细裂纹检测，不将视觉未见异常解释为结构安全。对象数由场景尺寸及可见关系确定，不为打败depth3而增加。

## 2. 数据与可见信息合同

| 资源 | 内容 | 策略可见性 |
|---|---|---|
| reference_session | 首次RGB-D、内参、位姿估计、资产及表面记录 | 所有方法相同 |
| current_observation | 本次已获得RGB-D、里程计及估计质量 | 可见 |
| task | 明确资产位置ID、历史ROI、目标属性、质量要求 | 所有方法相同 |
| current_map_estimate | 只由已采集观测构建 | 可见 |
| action_set | 可执行移动、转动相机、采集、停止，附运动约束 | 可见 |
| evaluator_truth | 真值位姿、对应、变化、光照及完整场景 | 仅评价器 |
| output_record | 历史／当前帧ID、对应ROI、后验、证据不足标记、动作和资源 | 全量保存 |

历史地图与定位误差来自前端，或明确标注的受控扰动；两者分别报告。新方法不能独享更准确位姿。初版可以使用已知局部飞行状态，隔离跨次估计；固定部分不能被声称已经解决。

## 3. 环境验收

- 输出历史／当前图像对和三维相机轨迹，检查来自不同采集及视角。
- 仅改变照明或视角，物理变化真值必须不变。
- 保持相机位姿而改变表面状态，图像应出现对应可见差异。
- 遮挡造成未检测时，不得直接生成移除标签。
- 相机转动必须改变视场；机体与云台相反转动若相机世界姿态不变，图像应按渲染设定保持一致。
- 关联和视点候选只能来自公开输入；候选缺失正确项单独记录。
- 至少一个可完成样例和一个不可观测样例通过真值诊断。
- 拍摄返回图像并再次推断，不能像旧finish宏一样直接结束并赋予成功。
- 未来图像只能执行动作后取得；渲染缓存可加速，但策略不能预览。
- 独立记录碰撞、不可达和返航资源；不能把真值安全路径作为所有方法无代价拥有的完整地图而不披露。

验收只证明机制和数据正确，不证明新算法有效。

## 4. 数据路线与成本边界

1. 开发样例：同一结构的两次RGB-D采集或可审计渲染，独立控制状态、相机运动、光照和遮挡。
2. 固定序列外部诊断：3RScan测试真实跨次关联；ChangeSim测试工业场景变化与非目标扰动。遵守官方获取、许可和划分，目前尚未下载。
3. 闭环：可交互桥梁／钢结构场景。可预生成位姿图，但边须对应运动路径，节点返回实际图像；结论限于提供的动作空间。
4. 动力学为后续层；第一轮各方法共享执行模型。重放固定录像不能证明能飞到未记录视点。

ChangeSim官方列出四个归档52.8、30.2、42.8、30.3 GB，合计156.1 GB。不能假设可低成本按单帧获取，先检查子集入口。代码许可不自动覆盖数据或底层资产。3RScan格式和标注说明已核验，实际获取和许可仍须按官方流程确认。[ChangeSim仓库](https://github.com/SAMMiCA/ChangeSim)、[3RScan仓库](https://github.com/WaldJohannaU/3RScan)

没有匹配素材时，记录数据缺口；自建仿真只能先支持机制研究，不可冒称真实工程验证。

## 5. 条件矩阵

四个二元因素组成16类设计条件：

| 因素 | 水平1 | 水平2 |
|---|---|---|
| C：真实变化 | 无局部变化 | 有可辨局部变化 |
| P：位姿 | 常规良好估计 | 跨次配准不确定 |
| A：关联 | 唯一上下文 | 重复构件、多种对应 |
| V：成像 | 充足可见质量 | 遮挡／光照干扰 |

物理上不可实现的组合要提前说明，不能跑完后删除。不能让光照、背景或纹理编码变化标签。

另有三个边界条件：准确配准且ID清楚；全部允许动作都无法区分真值；相机分辨率或可达性不足。

参数范围按资产尺度、实测前端误差或独立开发序列确定，并存入配置。不得反复扩大扰动直到新方法领先。重复结构只是一个因素，不代表整个工业任务分布。

## 6. 实验和对照

### E1：固定图像序列，比较状态估计

所有方法收到相同历史、当前帧、里程计和任务单：

- B0：明确ID／历史点选＋普通配准＋几何／图像差分＋质量门限。
- B1：B0加普通置信阈值、拒判及多视角聚合。
- B2：通用多假设关联／位姿估计＋相同变化检测器，避免将保留多解本身称为创新。
- B3：选择并适配FOCUS／OASIS-Map，以及可运行的Khronos或POV-SLAM参考。先核验代码、权重和接口；说明改动。自实现不能冒称官方完整复现。
- N：拟议证据模型，只替换证据因子／推断近似；不能独享更强骨干、更准确深度或更多帧。

真值诊断分别提供：真值位姿、真值关联、二者同时、充足可见图像。额外信息清楚标记，不作为公平对手，也不假设oracle诊断是所有算法的理论最优。

指标：对应准确率、候选召回、错误报告、变化精度／召回、概率校准、风险—覆盖曲线、运行时间和内存。像素IoU不替代资产级正确结论。

**固定帧下没有增益，就不能因闭环多拍照片声称新视觉表示成立。**

### E2：固定估计器，比较观察策略

所有方法共享动作、可见信息和执行成本：

- 固定轨迹复拍。
- 覆盖／可见质量驱动的视点选择。
- 普通不确定性或信息增益策略。
- 任务损失驱动一步VOI、通用短时域信念规划。
- 若确有新规划方法，再加入比较。

做“常规／拟议估计器 × 固定／通用主动观察”的交叉替换，拆分估计、策略和交互贡献。没有真实VLM时，不把VLM参数规模作为解释变量。

比较总观察数、路径、时间、资源及人工操作。既比较相同资源预算，也比较相同观察数。计时涵盖视觉特征、估计、预测和规划，不只计搜索根节点。

当前画面点选目标、可用编号和人工指认必须允许。人工效果未测时，分别给理想辅助上界及明确假设的成本敏感性，不伪造用户实验。

### E3：闭环任务和外部数据验证

冻结方法后，在未调参结构上评价：

\[
\mathrm{VerifiedCompletion}=
\frac{\#\{\text{正确资产及表面、合格证据、正确结论且满足资源}\}}
{\#\{\text{全部分配任务}\}}.
\]

同时报告：

- 错资产／表面，错误“无变化”，错误“变化”。
- 证据不足、报告覆盖率、条件错误率。
- 图像不可用、运动不可达、资源耗尽、超时。
- 可辨目标召回和不可辨目标上的拒判行为。

全部拒判不能取得任务成功。可行子集与全部任务分别报告，不能事后剔除难例。真实固定序列只支持所覆盖的感知结论，不能替代UAV闭环证据。

## 7. 划分、统计和停止规则

- 按物理场景／资产家族划分开发、校准、确认集；同场景相邻帧、不同光照和重访不能跨集泄漏。
- 第一轮可只跑无训练基线，先查机制与错误归因；确认集不用于改方法。
- 以独立场景为单位配对比较，不能将一座桥的千帧算成千个独立样本。
- 数据盘点后确定样本数。场景过少则报告探索性结论和区间，不伪造功效。
- 运行前规定可接受错误报告率及最小有用改善。没有业务方要求时，可设开发性门槛并做敏感性分析，须标为研究者设定。
- 确认集一次性评价；区间宽即未决，不反复换种子求显著。
- 16类条件按固定权重及逐类结果报告。无现场频率时，均匀均值只是基准分布。

| 结果 | 动作 |
|---|---|
| 强现成方法已达到所定要求 | 停止新算法开发 |
| 真值诊断仍不能取得有效图像 | 调整传感器或任务，不继续优化语义规划 |
| 只在自建极端条件有效 | 不扩写工业贡献 |
| 相同输入下估计有稳定增益，并传递到完整任务 | 才进入新方法研究 |
| 一轮冻结确认后证据不足 | 作方向判断，不再靠串行命名更小残差来延续课题 |

## 8. 紧接着的一个工作包

建立两次采集的可视样例包：

- 历史／当前RGB-D和相机轨迹；
- 明确任务单，隔离的变化／对应真值；
- 普通基线输出和逐项真值诊断；
- 历史／当前ROI、对应连线、遮挡与误报的解释图；
- 数据来源、相机参数、软件版本、运行命令和失败记录。

验收必须能指出哪张图、哪个关联、哪个视角造成结论。样例通过后再冻结多场景矩阵。没有图像和可执行视觉前端，就不能宣布已经开展历史视觉几何实验。
