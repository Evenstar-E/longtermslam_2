# 历史轨迹混淆：v6多位置记忆与历史独立校正实验

## Material Passport

- 状态：v6原型、六种初始方法、追加的历史校正对照均已实现并执行。
- 输入：128个保存的RGB-D基础场景；4种历史错误条件，共512个重复应力案例。没有生成512个新视觉场景。
- 初始实验：6方法×512案例=3,072条预测；追加历史独立校正512条。共3,584条主预测记录，512个案例仍来自同样128个基础场景。
- 补充评价：为计算历史参考位置合格的任务F1，重放全部3,072条初始预测；它们是重放，不是额外独立实验。
- 核心产物：`results/history_modes_v1/`、`results/history_alignment_control_v1/`。旧v1–v5、RGB-D数据与所有负面结果保留。
- 本轮结论：v6未胜出；保留位置模式不能自动修正模式的身份归属。历史独立校正是有效的常规对照，但没有超过可靠首帧参照，不能包装为新的原创贡献。

## 1. 本轮要解决的真实错误

跨次巡检中，如果跟踪器把外观相似构件的历史观测拼进同一轨迹，平均融合会产生并不存在的参考位置。随后系统可能把正常构件报成变位，也可能把真正变化归给错误的设施编号。

固定例子：基础场景0、名义轨迹0中，六个观测实际来自两个物理构件。历史帧0、2属于构件0，帧1、3、4、5属于构件12。均值约为[0.066,1.445,−0.002]m，离首帧有效参考约1.425m；没有任何一次观测位于该均值处。图`memory_example_v2.png`保留两个观测簇与虚假均值。

这比单纯全局坐标系偏差更直接地破坏相对参考证据。不过，**发现均值失败仍不能证明需要复杂新算法**：稳健中心、历史重新匹配、可靠首帧都是必须保留的对照。

## 2. 错误如何施加，哪些信息仍然已知

第一帧是给定的可靠、完整参考，覆盖全部24个构件，身份标签保持正确。后续五帧可以发生错误拼接。所有方法获得同样的第一帧，v6不额外获得正确身份。

按首帧实际观测描述子的相似度，贪心选择6个互不相交的构件对，即12/24轨迹参与混淆。交换某对在指定历史帧中的**位置与描述子**，而不是只改位置。每帧原始点集和一对一观测保持完整；发生错误的是它们挂载的轨迹标签。当前观测、当前真值、变化标签不参与错误对选择。

| 条件 | 后续历史轨迹错误 | 额外历史位姿误差 |
|---|---|---|
| clean | 无 | 无 |
| minority_mix | 每对在5个后续帧中错2帧：6次观测中4次正确、2次错误 | 无 |
| majority_mix | 每对错4帧：6次观测中2次正确、4次错误 | 无 |
| majority_pose | 同上一行 | 首帧不动，其他帧各有0.15m/2°标准差的相干SE(3)扰动 |

2°为旋转向量各分量标准差。位姿扰动同时作用该帧所有构件，不是各点独立随机删除或位移。基础场景固定取原16个视觉条件各自前8个，不按算法表现筛选。

历史中的物理构件在原图像序列里静态；当前仍有0/30%的真实粗尺度变位、重复外观及遮挡。该实验没有细微缺陷、新生/永久消失或非平面物体。

## 3. v6到底改了什么

v4把每条历史轨迹压成一个中心；v6按位置做完全链接聚类，半径门限0.36m，保留多个历史位置模式μ_jk、外观f_jk、模式支持数n_jk。

第一帧给定参考位置为a_j。模式代价为

\[
b_{jk}=-\log(n_{jk}/H)+\frac{\|\mu_{jk}-a_j\|^2}{2s_a^2},\qquad s_a=1m.
\]

它是未归一化能量，不是经过校准的模式概率。对于当前观测y_i及位姿T，构造

\[
L_{ij}(T)=\min_k\left[
\lambda d(g_i,f_{jk})+\|Ty_i-\mu_{jk}\|^2/\sigma_g^2+b_{jk}
\right].
\]

在名义身份j上用匈牙利算法做一对一匹配，同时由当前残差选模式k；再更新稳健位姿。模式三元组用于24个几何初值，另有给定初值，共25个、每个8次迭代。最终仍以稳健几何/外观/模式代价选解，0.25m变化门限不变。

**该模型允许选择位置模式，却没有把历史观测的模式身份重新分配给其他构件。** 一个实际属于构件1的位置模式，如果仍挂在名义轨迹2下，v6可能继续把它当作构件2。这是本轮需要检验的表示边界，而不是“多峰天然更可靠”的前提。

## 4. 保留的强常规对照

1. **mean**：历史均值＋v4。相同、无差别的测量协方差下，普通精度加权也退化到该均值。
2. **geomedian**：几何中位数位置及描述子＋v4，是迭代重加权的稳健单中心对照。
3. **anchor_only**：只用可靠第一帧＋v4，检验增加历史是否真有用。
4. **reassociate**：按首帧位置/外观，将每个历史帧重新做全局匹配后平均，不修正历史位姿。
5. **anchor_cluster**：只保留包含可靠首帧观测的位置簇并求均值，再运行v4；历史模式选择不看当前观测。
6. **v6_modes**：保留多模式，由当前几何与外观参与选择。

这六种方法和参数在结果之前固定。v6结果出来后，另追加了**历史独立校正**常规对照：对每帧历史点集用冻结v4向第一帧配准，同时重新分配身份；对齐和重排后融合，再运行当前v4。

\[
T_h,A_h\leftarrow\operatorname{Register}(Z_h,Z_0),\quad
\tilde z_{hj}=T_hz_{h,A_h^{-1}(j)},\quad
\bar x_j=H^{-1}\sum_h\tilde z_{hj}.
\]

此过程在构建历史参考时不使用当前观测。它复用已有配准，是追加的诊断对照，不命名为一个已验证原创“v7”，也不是独立确认集。

## 5. 任务分数与历史参照质量一起评价

身份感知变化F1仍将错误身份的变化报告计为误报/漏报，按每条件64个有真实变化的基础场景平均。另报告：所选历史参考点是否距离原干净历史参考均值≤0.25m。

补充“参考位置合格F1”进一步要求：当前身份正确、历史参考位置合格、变化判断正确。所有方法同样计算，不丢弃预测，不通过拒判缩小分母。它是对参考几何质量的检查，**不是唯一物理身份的完整证明**。

该补充指标在主预测后由独立评分脚本计算，为获取逐观测结果重放全部方法，没有据其调算法。首帧固定了本实验的参考坐标规范；此处不是上一轮将共同全局偏差换坐标系后择优报告。

还应注意：**无位姿误差的多数拼错条件中，几何中位数位姿通过100%，身份准确率却只有49.52%。** 正确配准物理点集不等于正确分配设施编号，不能只看位姿成功率决定巡检算法价值。

v6对首帧簇的参考合格F1差：多数拼错约−0.0503，条件内配对bootstrap探索95%区间[−0.0954,−0.0135]；混合位姿误差条件约−0.4251，区间[−0.4884,−0.3642]。没有多重比较校正，不把它们当外部环境普遍结论，但本批数据不支持v6胜出。

v6耗时中位数约78–122ms；仅首帧约21–32ms；历史独立校正约244–274ms，包含5次额外历史配准和一次当前配准。历史校正可设为离线步骤，但本轮没有分别测量缓存建图与查询耗时，不能据此宣称实时性能无代价。

## 7. 逐例核验：到底是什么错误

场景84、多数拼错条件中：

- 当前观测12的真实构件身份为1，确实发生变位。
- v6却报告“名义构件2发生变位”，残差约0.784m。
- 它选择的历史模式包含帧1、2、4、5；这四次历史观测的真实物理身份**全是构件1**，只是被错拼到轨迹2。

对应证据保存在`identity_failure_trace.json`。此例说明：位置模式保存了构件1的位置，却没有纠正错误的模式归属，最终把变化归给错误资产。该案例按结果选择用于诊断，不能拿一个案例当成功率。

同时，本轮还定向检索了128个有变化应力案例，寻找更严格的“当前身份正确、却选错历史模式而把真实变位判成未变”的案例，**没有找到满足该条件的实例**（`failure_trace.json`）。因此不能将整体F1下降直接解释成已证实的“变化被吸收”；那仍是模型风险。本轮已证实的是身份归属和参考位置错误。

## 8. 算法取舍与下一步

**不将v6提升为主干，不继续靠调模式先验争取这组数据上的胜出。** 保留它和负面结果；历史独立校正作为更强的预处理参照，当前判断仍使用冻结历史参考与v4。

但历史独立校正并没有优于只用可靠首帧的任务F1。当前场景给了第一帧完整、准确的24构件参考，且每个构件被压缩成一个三维点，这使单帧参照天然很强。不能据此宣称“多帧记忆已证明必要”，也不能把配准预处理包装成已确立的原创贡献。

下一阶段应把观测模型推进到**非平面构件的部分表面观测**：不同视角下检测区域中心不再代表同一个三维物理点，单帧无法提供完整的历史形状参考。新算法应针对跨视角表面对应、历史身份归属与真实形变的区分，和强多视图/稳健几何方法直接比较。不是把已有均值问题进一步缩成调门限，也不再在完整首帧的理想点场景上扩大种子刷分。该下一阶段尚未在本轮实现。
